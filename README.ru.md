## Что опубликовано

Исходники Solidity, тесты локальной EVM, вспомогательный код подготовки покупки и проверки квитанции, инструкция сборки, скрипт чтения и сверки байткода BSC. Сайт, база клиентов, документы KYC, ключи и настройки сервера в репозиторий не входят.

`deployments/bsc-mainnet.json` — снимок на указанном блоке: точное совпадение runtime-байткода с учётом metadata и immutable-параметров, текущие на этот момент настройки и владельцы Safe. Владельцы, получатель оплаты, пауза и разрешение переводов могут меняться; для актуальной проверки запускайте скрипт заново.

**Важно: в снимке от 24.11.2026, блок 135486561, владельцы различаются.** HRP принадлежит Safe `0xBabfE0Fc7C1de0d283B2cf95E61D570aBF5E6c79`, продажа — Safe `0xA2aA81FCF7dd61D77bd09AFF680c997Ca989E437`. Оба имеют двух владельцев, порог 2 и не имеют включённых модулей. Смена получателя USDT, подписанта допуска и оператора выдачи в продаже требует совпадения владельцев и при таком состоянии завершится откатом. Само различие владельцев не доказывает невозможность покупки; реальная покупка в рамках публикации не выполнялась. На момент снимка обычные переводы HRP заблокированы, продажа не на паузе. Публикация не меняет эти настройки.

Внешний независимый аудит **не проводился**. Тесты и совпадение байткода не заменяют аудит. Публикация исходников не меняет контракты, не открывает переводы и не создаёт рыночную цену. Исторические комментарии «pre-release» оставлены без изменения, чтобы сохранить воспроизводимость исходников.

## Сборка

Node.js 22+ и npm:

```sh
npm ci --ignore-scripts
npm test
npm run verify:mainnet
```

Solidity **0.8.38**, OpenZeppelin **5.6.1**, optimizer **200 runs**, EVM **Paris**. Тесты выполняются локально с mock USDT и не расходуют реальные средства. Скрипт `verify:mainnet` только читает RPC, не подписывает и не отправляет транзакции. Другой RPC можно задать переменной `BSC_RPC_URL`.

## Условия и ограничения

- Эмиссия фиксирована: **20 млн HRP**, 18 знаков. Внешних функций дополнительной эмиссии, сжигания и proxy-обновления нет.
- При создании компания получает **19,6 млн**, резерв — **400 тыс.** После однократного финансирования продажи **3,79 млн** в компании остаётся **15,81 млн HRP**.
- Лот: **100 HRP за 100 USDT**. Цена продажи не гарантирует стоимость на рынке или обратный выкуп.
- Лимиты пяти раундов: **2 000 / 6 000 / 8 000 / 10 000 / 1 000** оплаченных лотов. Бонусы: **100 / 60 / 40 / 20 / 10%**.
- До накопления десяти оплаченных лотов бонуса нет. При пересечении порога бонус по ставке текущего раунда начисляется на все накопленные лоты; после — только на новые. Учёт ведётся по адресу покупателя. Покупка не пересекает границу раунда, раунды переключает владелец.
- Закрытие новых покупок: **25 января 2027, 07:00 UTC (10:00 МСК)**. Для зарезервированных оплат из других сетей действуют отдельные сроки завершения.
- Партнёрские начисления и накопительные привилегии кабинета не являются этим токен-бонусом и не реализованы в данных двух контрактах.
- Обычные переводы управляются общей блокировкой, включая компанию и резерв. При блокировке предусмотрена отдельная выдача покупок контрактом продажи. Разрешение и заморозка обычных переводов требуют проверяемого управления Safe 2 из 2 без модулей.
- Допуск к покупке: список разрешённых адресов либо краткосрочное EIP-712 разрешение служебного подписанта. KYC проверяется кабинетом и службой, не Solidity-контрактом.
- Оплаты ERC20/TRC20 подтверждает ограниченный служебный оператор. Контракт в BSC не проверяет эти сети самостоятельно; компрометация службы представляет риск. HRP во всех случаях выдаётся в BSC.
- Есть отключённый по умолчанию механизм подключения отдельного контракта выкупа с согласием держателя. Сам платёжный контракт выкупа здесь отсутствует; возможность выкупа не обещается.

Исходники сохраняют исходный статус **UNLICENSED**. Публикация не назначает новую открытую лицензию. Лицензии сторонних пакетов указаны отдельно.
